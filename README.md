## Featured Portfolio Projects

### [Risk Acceptance and Security Exception Management](https://github.com/RAY883/Risk-Acceptance-Security-Exception-Management)

Assessed a shared privileged-account weakness in a fictional international payment-technology company. Compared five treatment options, evaluated compensating controls, assigned the correct business risk owner and produced a conditional security-exception decision with expiry, monitoring and remediation requirements.

**Key evidence:** 5×5 risk assessment, threat scenarios, control-effectiveness review, residual-risk analysis, Excel remediation tracker, management dashboard and Python-generated GRC evidence workbooks.

### [AI Security Governance and Incident Readiness](https://github.com/RAY883/AI-Security-Governance-and-Incident-Readiness)

Built and assessed a controlled AI assistant scenario covering prompt injection, sensitive-data protection, RBAC, security logging, Splunk monitoring, incident readiness and risk-based deployment decision-making.

**Decision:** Limited pilot only under defined security and governance conditions.

### [Third-Party Cloud Vendor Risk Assessment](https://github.com/RAY883/third-party-cloud-vendor-risk-assessment)

Completed a structured third-party cloud vendor assessment covering vendor tiering, eight risk areas, control review, NIST CSF 2.0 mapping, contractual requirements and residual risk.

**Decision:** Approve with Conditions.

### [IAM Joiner, Mover and Leaver Access Governance](https://github.com/RAY883/iam-joiner-mover-leaver-access-governance)

Designed an access-governance process covering Joiner–Mover–Leaver controls, RBAC, least privilege, segregation of duties, privileged access, access reviews, termination controls and audit evidence.

### [Enterprise Active Directory and Splunk SIEM Lab](https://github.com/RAY883/active-directory-splunk-siem-lab)

Built a Windows Server 2022 Active Directory environment with a domain-joined Windows 11 client, Splunk Enterprise and centralized Windows event collection. The lab gives me a reusable technical environment for security monitoring and control-validation work.
