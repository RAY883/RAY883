# About Me — SOC, VAPT & Technical Security

My second cybersecurity track is focused on **SOC/security operations, VAPT, AI security and IAM**. I use this track for roles where recruiters want stronger evidence of hands-on investigation, security monitoring and technical validation.

I have built and documented an enterprise-style Active Directory and Splunk SIEM lab, worked with Windows security events and centralized logging, and completed practical investigation work using Wireshark and VirusTotal. I have also used Burp Suite and other web-security tools to understand common application-security weaknesses and how technical findings should be reported and remediated.

I do not treat this technical work as separate from governance. It helps me understand whether a control is actually operating, what evidence it produces and what a security analyst should escalate when something goes wrong.
